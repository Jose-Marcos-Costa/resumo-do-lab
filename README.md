
# Resumo do Laboratório: Benefícios da Computação em Nuvem

Este repositório contém o resumo das lições aprendidas durante o desenvolvimento do lab na plataforma DIO, que trata sobre os benefícios da computação em nuvem. (Bootcamp XP Inc. - Cloud com inteligência Artificial)

## Resumo

Nesse laboratório, a relação entre o SLA (Service Level Agreement) ou Acordo de Nível de Serviço e o Tempo de Inatividade para os períodos de semana, mês e ano. Verificou-se ainda que quanto maior a precisão do SLA mais oneroso e, menor será o tempo de inatividade. Em casos em que o tempo indisponibilidade é maior que o previsto pelo SLA, e isso se dá por motivos ligados à Microsoft, o cliente é ressarcido.
Foi possível entender ainda que, ao ser requisitado um recurso na nuvem, o profissional de cloud deve questionar o requisitante quanto ao tempo de inatividade aceitável do projeto.
Verificou-se ainda que ao criar as Máquinas Virtuais/Contas de Armazenamento no Microsoft Azure, as especificações escolhidas (Opções de disponibilidade, Zona de disponibilidade, Redundância) irão influenciar diretamente no SLA do projeto.
